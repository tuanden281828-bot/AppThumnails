# AI Photo Studio

App tạo ảnh đăng mạng xã hội: chèn headline + badge thương hiệu lên ảnh (phong cách Phong Menly).

## Cách dùng

Mở file `index.html` bằng trình duyệt (Chrome/Edge) — không cần cài đặt gì, font Lato-Black đã nhúng sẵn, hỗ trợ đầy đủ dấu tiếng Việt.

## Chức năng

- Kéo-thả / chọn nhiều ảnh, tự crop cover, chỉnh vị trí crop dọc
- Headline chữ trắng đậm, bọc từ khoá trong `**...**` để tô neon vàng-chanh
- Tự co font (72→42) để không bao giờ quá 2 dòng, ngắt dòng cân đối
- 🪄 Tự trích headline từ bài viết dài (ưu tiên câu có số liệu, hook, bài học)
- Badge bo tròn góc dưới phải, sửa text hoặc ẩn được
- Tuỳ chỉnh màu neon, độ đậm gradient, 3 kích thước: 4:5 / 1:1 / 9:16
- Xuất hàng loạt: nhiều ảnh × nhiều headline, tải tất cả
- Tải JPG (chất lượng 95%) hoặc PNG
